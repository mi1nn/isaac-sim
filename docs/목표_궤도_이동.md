## 상세정보

## 1. 구현 목적

MEP가 Client Satellite에 도킹된 이후,

**MEP + Client Satellite 결합체가 목표 운용 궤도(Target Operational Orbit)로 이동하는 과정**을 구현한다.

현재 프로젝트에서는 실제 궤도역학과 Thruster의 추력을 정밀 계산하는 것이 핵심이 아니므로,

> **도킹 완료 → 로봇팔 분리 → 목표 궤도로 부드럽게 이동 → 목표 궤도 추종**
> 

과정을 시각적으로 구현한다.

※ 실제 궤도 천이 물리 시뮬레이션이 아니라 **MEP 추진을 통한 목표 운용 궤도 복귀 과정의 시각화**를 목표로 한다.

---

## 2. 전체 진행 흐름

MEP 탐색 및 포획

→ MEP ATTACHED

→ Client Satellite 접근

→ Probe Docking

→ **DOCKED**

→ MEP ↔ Satellite 결합 확인

→ Canadarm3 ↔ MEP 연결 해제

→ Canadarm3 후퇴

→ **ORBIT_TRANSFER**

→ MEP + Satellite가 곡선 경로를 따라 이동

→ Target Orbit Entry Point 도착

→ **ORBIT_FOLLOW**

→ 빨간 목표 궤도를 따라 이동

→ **MISSION SUCCESS**

---

## 3. 목표 궤도 표시

### Target Operational Orbit

시뮬레이션이 시작될 때부터 **빨간색 원형 궤도**를 표시한다.

- 궤도는 실제 물리 객체가 아닌 시각화 요소
- 질량 및 충돌 없음
- MEP 포획 및 도킹 물리에 영향을 주지 않음
- 프로젝트에서 사용할 목표 궤도의 위치와 크기는 시뮬레이션 환경에 맞게 임의 설정

### 화면 예시

```
          TARGET OPERATIONAL ORBIT

            🔴 🔴 🔴 🔴 🔴
        🔴                 🔴
     🔴                       🔴
    🔴                         🔴
     🔴                       🔴
        🔴                 🔴
            🔴 🔴 🔴 🔴 🔴
```

## 4. 도킹 완료 후 로봇팔 분리

Satellite와 MEP의 도킹이 완료되면 바로 궤도로 이동시키지 않는다.

먼저 다음 순서로 결합 상태를 정리한다.

1. MEP ↔ Satellite 도킹 성공 확인
2. MEP ↔ Satellite FixedJoint 유지
3. Canadarm3 ↔ MEP FixedJoint 해제
4. Canadarm3 후퇴
5. Satellite + MEP만 남은 상태 확인

### 결과

[ Canadarm3 ]        [ Client Satellite ─ MEP ]
↓                            ↓
RETREAT                  하나의 결합체로 이동

---

## 5. Satellite + MEP 결합 상태 유지

도킹 순간의 Satellite와 MEP 사이의 상대 위치 및 자세를 저장한다.

즉,

> **MEP가 Satellite의 어느 위치와 방향에 부착되어 있는지 저장**
> 

한다.

이후 궤도로 이동하는 동안 이 상대 관계를 유지한다.

### 개념

이동 전

Satellite ───── MEP
고정된 상대 관계

이동 중

```
    Satellite ───── MEP
```

궤도 도착

```
                Satellite ───── MEP
```

두 물체의 World 위치는 계속 변하지만

**Satellite ↔ MEP 사이의 상대 위치와 자세는 동일하게 유지**한다.

---

## 6. 목표 궤도 Entry Point 설정

빨간 목표 궤도 위에 하나의 진입 지점을 미리 지정한다.

이를

**Target Orbit Entry Point**

로 사용한다.

```
                   ★ Entry Point
                🔴 🔴 🔴
             🔴           🔴
           🔴               🔴
             🔴           🔴
                🔴 🔴 🔴
```

Satellite + MEP가 임의의 위치에서 복잡하게 궤도를 찾도록 하지 않고,

먼저 이 Entry Point를 목표로 이동시킨다.

---

## 7. 궤도까지 부드럽게 이동

도킹 위치에서 Entry Point까지 직선으로 순간 이동시키지 않는다.

중간 경로를 추가하여 **곡선 형태의 Transfer Path**를 생성한다.

### 이동 과정

Satellite + MEP
●
╲
●
╲
●
╲
●
╲
★ Target Orbit Entry Point

### 사용 방법

시작점

- 도킹 완료 후 Satellite 위치

중간점

- 자연스러운 곡선을 만들기 위한 Control Point

끝점

- Target Orbit Entry Point

### Bézier Curve 사용

곡선 경로는 간단한 Bézier Curve를 사용하여 생성할 수 있다.

P(t) = (1-t)²P₀ + 2(1-t)tP₁ + t²P₂

- P₀ : 도킹 완료 위치
- P₁ : 곡선 경로를 만들기 위한 중간점
- P₂ : Target Orbit Entry Point
- t : 0 → 1

`t` 값을 천천히 증가시키면 Satellite + MEP가 곡선을 따라 자연스럽게 이동한다.

## 8. 목표 궤도 도착 후 이동

Entry Point에 도착하면 상태를

**ORBIT_TRANSFER → ORBIT_FOLLOW**

로 변경한다.

원형 목표 궤도는 다음과 같이 정의할 수 있다.

x = xc + R cos(θ)

y = yc + R sin(θ)

z = zc

이후 θ 값을 계속 증가시키면 Satellite + MEP가 빨간 궤도를 따라 이동한다.

### 결과

```
             🛰️ + MEP →
          🔴 🔴 🔴 🔴 🔴
       🔴                 🔴
     🔴                     🔴
       🔴                 🔴
          🔴 🔴 🔴 🔴 🔴

          ORBIT_FOLLOW
```

## 9. 최종 State 구성

기존 MEP Capture / Satellite Docking State 뒤에 아래 상태를 추가한다.

### MEP Capture

MEP_SEARCH

→ TRACKING

→ APPROACH

→ ALIGN

→ MEP_ATTACHED

### Satellite Docking

DOCK_SEARCH

→ PRE_DOCK

→ ALIGN

→ DOCKED

### Orbit Transfer

ORBIT_TRANSFER

→ ORBIT_FOLLOW

→ ORBIT_REACHED

→ MISSION_SUCCESS

## 10. 실제 구현 순서

한 번에 전체 궤도 이동을 구현하지 않고 아래 순서로 테스트한다.

### STEP 1

시뮬레이션 시작부터 빨간 Target Orbit 표시

### STEP 2

기존 MEP Capture 및 Satellite Docking에 영향을 주지 않는지 확인

### STEP 3

DOCKED 이후 Canadarm3 ↔ MEP 연결 해제

### STEP 4

Canadarm3 후퇴

### STEP 5

Satellite + MEP를 약 1 m 정도 같이 이동시켜 결합 상태 유지 확인

### STEP 6

직선 이동 테스트 성공 후 Bézier Curve 기반 곡선 이동 적용

### STEP 7

곡선 경로의 끝점을 Target Orbit Entry Point와 연결

### STEP 8

Entry Point 도착 후 빨간 원형 궤도 추종

### STEP 9

ORBIT_REACHED / MISSION_SUCCESS 상태 추가

## 12. 발표 시 설명

> Client Satellite에 MEP를 도킹한 후 Canadarm3를 분리하고, MEP의 추진 기능을 이용한 목표 운용 궤도 복귀 과정을 시각화하였습니다.
> 
> 
> 도킹된 Satellite와 MEP의 상대 위치 및 자세를 유지하면서 곡선 형태의 Transfer Path를 따라 목표 궤도에 진입하고, 이후 Target Operational Orbit을 따라 이동하도록 구성하였습니다.
> 

### 주의

현재 구현은 실제 궤도역학을 이용하여 MEP의 정확한 추력과 ΔV를 계산하는 시스템이 아니다.

따라서

**❌ 실제 궤도역학 기반 궤도 천이를 구현하였다**

보다는

**⭕ MEP 추진을 통한 목표 운용 궤도 복귀 과정을 시각화하였다**

라고 설명하는 것이 정확하다.
